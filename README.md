# Trend to Post

An automated X publishing queue for practical developer prompt tips and text-free comparison memes. The repository is designed to publish one main post per eligible run, track daily quotas in Git, and make generation/publishing failures visible in GitHub Actions.

## Active daily plan

- **22 builder prompt posts/day** — substantial, paste-ready briefs for AI coding tools and polished websites, apps, and UI/UX. Each prompt specifies the actual product flow, design system, responsive rules, accessibility, interaction states, and visual QA.
- **22 comparison memes/day** — original two-choice captions and images. The caption has exactly this two-section format (this is the only example; its pair is not a reusable post):

  ```text
  Grok Bot or ChatGPT Dots?

  Be honest...
  ```
- **No X Trends quote-posts or real-person photo prompts** — those lanes are not part of the active plan.

The **hard daily cap is 45 posts**. The two requested lane quotas total **44** (22 + 22), so the 45th slot remains reserved rather than creating an unrequested third lane. Posts are spaced by at least 30 minutes. The queue stops at either lane quota, and state is stored in `state/post_queue.json` and committed back to `main` by the posting workflow.

## Image generation

Comparison art is generated with Cloudflare Workers AI using **FLUX.1 [schnell]** (`@cf/black-forest-labs/flux-1-schnell`) through the account REST API. The request includes a strict composition prompt based on the supplied reference: a vertical 50/50 split, light gray on the left, mint/turquoise on the right, a central outlined “VS”, a single bold left-side visual, and a group of colorful fuzzy 3D mascots on the right. The caption is outside the image. The prompt forbids logos, captions, watermarks, accidental text, and visual defects.

Generated bytes are validated as a real PNG or JPEG, checked for usable resolution, and rejected if corrupt or oversized. There is **no local SVG fallback**: when Cloudflare rejects a request or the daily quota is exhausted, no comparison image/post is published and the reason is visible in logs. See [Cloudflare's FLUX.1 schnell model docs](https://developers.cloudflare.com/workers-ai/models/flux-1-schnell/) and [Workers AI pricing/free allocation](https://developers.cloudflare.com/workers-ai/platform/pricing/).

## AI text generation

Cloudflare Workers AI remains the primary first-pass provider for non-builder text candidates. Gemini generates builder prompts and handles text fallback. The same Cloudflare account ID and API token are used for text and FLUX image generation. Configure `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`, and `GEMINI_API_KEY`; `GEMINI_API_KEY_BACKUP` is optional.

Builder posts target approximately **600–1,400 characters** to provide genuinely reusable prompts. Long-form X publishing requires an account with long-post permission (typically X Premium). The app intentionally does not silently shorten these posts; if the X account cannot publish long posts, publishing will fail visibly and the account entitlement must be resolved.
 
## Workflows

- `.github/workflows/post-queue.yml` runs every 30 minutes with a 30-minute minimum-post interval, on manual dispatch, or on the `post-next` repository-dispatch event. It installs dependencies, validates syntax, runs tests, attempts one queue item, and commits state changes.
- `.github/workflows/test.yml` runs compile checks and the full unit-test suite on pushes, pull requests, and manual dispatch.

A successful validation workflow proves the code and tests passed; it does **not** prove an X post was published. Confirm publishing from the posting workflow's logs and its `published` output.

## Setup

Install Python 3.12 and dependencies:

```bash
python -m pip install -r requirements.txt
python -m compileall -q app
python -m unittest discover -s tests -p "test_*.py"
```

Configure these GitHub Actions secrets:

- `X_AUTH_TOKEN` — required X session authentication cookie.
- `X_CT0` — required X CSRF cookie.
- `GEMINI_API_KEY` — required when Gemini fallback is needed.
- `GEMINI_API_KEY_BACKUP` — optional second Gemini key.
- `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` — required for first-pass text candidates and FLUX.1 [schnell] comparison images.

The X cookies are session credentials and may expire. Keep all credentials in GitHub Secrets; never commit them to the repository or print their values in logs.

## Reliability and safety notes

- The queue enforces the 45-post hard cap and the 22/22 active lane quotas.
- Failed generation should be reported as a failure, not treated as an empty queue.
- A post whose X publishing outcome is uncertain must not be blindly retried, because that could create a duplicate.
- State commits use retry/rebase logic to handle concurrent updates.
- Wikimedia/person-photo and retired quote-post code may remain for backward compatibility; they are not the active comparison-image path.
- FLUX.1 [schnell] uses Cloudflare Workers AI's 10,000-Neuron free daily allocation where available; this limit is shared with other Workers AI usage and can be exhausted.
- This project uses Twikit with an authenticated X session. Review [X's automation rules](https://help.x.com/en/rules-and-policies/x-automation) and use an approved publishing method consistent with current platform requirements.
