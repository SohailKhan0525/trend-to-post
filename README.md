# X Trend to Post

Personal production content engine for X Trends in Technology and Artificial Intelligence.

Scope: X Trends are the only discovery source. Gemini generates original draft posts. GitHub stores the reviewable output. This repository does not automatically publish to X.

X currently prohibits automated posts about Trending Topics, so the output is deliberately a human-review queue rather than an auto-publisher.

Designed for Android + Termux.

## Commands

python -m app health
python -m app trends
python -m app generate
python -m app run
